# Мальописи — картковий набір (сайт)

Статичний сайт: титулка і 4 сторінки з історіями. Усі файли лежать в одній папці, без підпапок.
Працює без сервера й без інтернету (можна просто відкрити `index.html` подвійним кліком).

## Що де лежить

- `index.html` — титулка; `istoriia-1.html` … `istoriia-4.html` — сторінки історій
- `data.js` — назви, підписи, інструкція, кольори і список карток кожної історії
- `01.webp` … `47.webp` — картки (номер = номер сторінки з макета карток)
- `1.webp` … `4.webp` — зображення для титулки; `logo.png` — лого; `favicon.png` — іконка вкладки
- `style.css`, `app.js` — вигляд і логіка; `shantell-sans-*.woff2` — шрифт (ліцензія OFL, `OFL.txt`)

## Як змінити

- **Текст підпису чи інструкції** — відредагуйте `data.js`.
- **Замінити картку** — завантажте нове зображення з тією самою назвою файлу.
- **Колір історії** — блок `colors` у `data.js` (`header` — колір хедера й кнопок, `tint` — фон сторінки, `tint2` — фон зони «Картки»).
