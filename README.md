# Мальописи — картковий набір (сайт)

Статичний сайт: титулка і 4 сторінки з історіями. Працює без сервера й без інтернету
(можна просто відкрити `index.html` подвійним кліком).

## Що де лежить

- `index.html` — титулка
- `istoriia-1.html` … `istoriia-4.html` — сторінки історій
- `data.js` — назви, підписи, інструкція, кольори і список карток кожної історії
- `images/istoriia-N/` — зображення карток (номер файлу = номер сторінки з макета)
- `images/titulka/` — зображення для титулки, `images/logo.png` — лого
- `assets/` — стилі, код і шрифт Shantell Sans (ліцензія OFL)

## Як змінити

- **Текст підпису чи інструкції** — відредагуйте `data.js`.
- **Замінити картку** — покладіть нове зображення з тією самою назвою файлу в ту саму папку.
  Якщо формат інший (.jpg, .png) — змініть шлях у `data.js`.
- **Колір історії** — блок `colors` у `data.js` (`header` — колір хедера й кнопок, `tint` — фон сторінки, `tint2` — фон зони «Картки»).
